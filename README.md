# 클로드 코드 실습자료 (학생용)

클로드 데스크톱 앱(Code 탭)에 과제 · 시험 공부 · 팀플 · 동아리 일을 맡겨 보는 실습용 자료입니다.
모든 파일은 가상 «한울대학교» 2학년 학생의 **가상 자료**입니다. 이름 · 점수 · 측정값은 모두 지어낸 것이고 실제 기관 · 인물과 관계없습니다.

## 내려받기

1. 이 페이지 위쪽의 초록색 **Code** 버튼을 누르고 **Download ZIP**을 누릅니다.
   - 바로 받기: https://github.com/wdyd2004/claude-code-student-kit/archive/refs/heads/main.zip
2. 내려받은 zip 파일의 압축을 바탕화면에 풉니다. 압축을 풀지 않으면 클로드가 안의 파일을 읽지 못합니다.
3. 클로드 데스크톱 앱 왼쪽 위 **Code**를 누르고, 입력 칸 위 **폴더 선택…**에서 압축을 푼 폴더 안의 **실습자료** 폴더를 고릅니다.

실습은 모두 이 «실습자료» 폴더 하나에서 합니다. 실습마다 왼쪽 **＋ 새로 생성**으로 새 대화를 열고 시작합니다(앞 실습을 이어 하는 실습만 같은 대화에서 합니다).

## 폴더 구성

| 폴더 | 들어 있는 자료 | 쓰는 실습 |
|---|---|---|
| 동아리 | 작년 사진전 안내 · 부원 명단 · 회비 기준 | ② 작년 안내문을 올해 버전으로 · ③ 부원마다 회비 안내 |
| 팀플 동료평가 | 팀원 평가지 6개 · 평가 방법 | ④ 팀원별 기여 점수 |
| 성적 | 성적표 · 졸업 요건 | ⑤ 학점 계산 · 졸업 요건 점검 · ⑥ 학점 대시보드 |
| 강의 자료 | «생활 속 미생물» 강의계획서 · 7주차 강의 장표 | ⑦ 시험 대비 요약 장표 · ⑧ 모의고사 · ⑨ 복습 퀴즈 · ⑪~⑬ · ⑮ |
| 실험 보고서 | 측정값 · 실험 노트 · 실험 안내 · 작년 예시 보고서 | ⑩ 우리 조 실험 보고서 초안 |
| 오답 노트 | 7주차 쪽지시험 문제지 · 채점 결과 | ⑭ 오답 노트와 wrong-note 스킬 |

실습 중에 만든 스킬은 이 폴더 안의 `.claude/skills/`에 저장됩니다.

## 지킬 것

- 이 자료는 실습용 가상 자료입니다. 실제 내 성적 · 친구의 정보 · 공개되지 않은 시험 문제는 넣지 않습니다.
- 강의 장표는 내 공부에만 쓰고 다른 곳에 올리지 않습니다.
- 클로드가 만든 결과(숫자 · 출처 · 정답)는 원본과 직접 대조합니다.
